# DESIGN.md

Дизайн-токены сайта Натальи Селезнёвой. Реальные значения из компонентов `site/src`, зафиксированные как эталон. Читай перед любой UI-задачей — новые элементы собираются из этих значений, а не придумываются заново.

## Шрифт

Единственный шрифт сайта — `Georgia, serif` (задан глобально в `site/src/index.css`, отдельно подключать не нужно).

Начертания:
- `font-light` (300) — заголовки, кнопки, крупные цифры. Основное начертание для всего "выразительного" текста.
- обычное (400, без класса) — текст абзацев.
- `italic` — акцентная вставка внутри заголовка (одно слово/строка), не самостоятельный стиль.

## Цвета

Палитра — стандартный Tailwind `stone`, кастомных цветов в конфиге нет.

| Класс | Hex | Где использовать |
|---|---|---|
| `stone-50` | `#fafaf9` | Фон светлых секций (About, Process), заливка карточек-без-рамки |
| `stone-100` | `#f5f5f4` | Hover-фон светлых кнопок |
| `stone-200` | `#e7e5e4` | Рамки карточек, разделители |
| `stone-300` | `#d6d3d1` | Рамки второстепенных элементов на белом фоне |
| `stone-400` | `#a8a29e` | Приглушённый текст, мелкие лейблы |
| `stone-500` | `#78716c` | Второстепенный текст |
| `stone-600` | `#57534e` | Текст абзацев |
| `stone-700` | `#44403c` | Рамки полей формы, hover-текст |
| `stone-800` | `#292524` | Тёмные разделители (футер) |
| `stone-900` | `#1c1917` | Основной тёмный: заголовки, primary-кнопки, тёмный фон секций |
| `white` / `black` | `#ffffff` / `#000000` | Базовые + оверлеи (`/50`, `/30`, `/90`) поверх фото |
| `red-500` / `red-400` | `#ef4444` / `#f87171` | Только состояние ошибки формы (граница / текст) |

**Правило:** фон и текст страницы — `bg-stone-50` / `text-stone-900`. Не используй кастомный hex для "почти чёрного" или "почти белого" — в `index.css` это `#fafaf8`/`#1a1a1a`, оставлено как legacy-исключение, новые элементы на них не заводить.

| `text-sm` | 14px | Навигация, кнопки, второстепенный текст |
| `text-base` (по умолчанию) | 16px | Текст абзацев |
| `text-lg` | 18px | Подзаголовок Hero, цена услуги |
| `text-xl` | 20px | Заголовок этапа (Process) |
| `text-2xl` | 24px | Заголовок в модалке/карточке услуги |
| `text-3xl` | 30px | Крупные цифры (статистика About) |
| `text-4xl md:text-5xl` | 36→48px | **Стандартный заголовок секции (H2)** |

## Типографика — межбуквенный интервал (tracking)

Капс-подписи (`uppercase`) используют ровно два значения:

- **`tracking-[0.4em]`** — эйбрау-подписи секций (маленький текст-категория над заголовком: "Работы", "Услуги" и т.п.) и подзаголовок Hero.
- **`tracking-widest`** — всё интерактивное: кнопки, ссылки навигации, бейджи, фильтры.

**Правило:** не использовать `tracking-wider` и одиночный `tracking-[0.3em]` — это исторические варианты того же паттерна, для новых элементов не заводить.

## Кнопки

Три размерных уровня, единая логика цвета:

| Уровень | Классы | Когда |
|---|---|---|
| Крупная CTA | `px-8 py-4 text-sm tracking-widest uppercase` | Hero, финальный призыв секции (1 на секцию, максимум) |
| Средняя | `px-5 py-3 text-sm tracking-widest uppercase` | Кнопка внутри карточки/блока |
| Малая (пилюля-фильтр) | `px-5 py-2 text-sm tracking-widest uppercase border` | Переключатели/фильтры |

Цветовые варианты:
- **Primary (тёмная)**: `bg-stone-900 text-white hover:bg-stone-700`
- **Primary на тёмном фоне (светлая)**: `bg-white text-stone-900 hover:bg-stone-100`
- **Outline на светлом фоне**: `border-stone-900 text-stone-900 hover:bg-stone-900 hover:text-white`
- **Outline на тёмном фоне**: `border-white text-white hover:bg-white hover:text-stone-900`
- **Disabled**: `opacity-50`, курсор по умолчанию (без доп. классов)

**Правило:** outline-кнопка на светлом фоне — всегда `border-stone-900`, не `border-stone-300`. Слабая рамка (`border-stone-300`) — только у фильтров/пилюль в неактивном состоянии, не у обычных кнопок.

Все кнопки/интерактивные ссылки: `transition-colors` или `transition-all duration-300`, без исключений.

## Карточки

Радиус скругления — **всегда 0** (`rounded-*` в проекте не используется вообще, это не забытая деталь, а стиль).

Два равноправных типа:
- **Тип А — с рамкой**: `border border-stone-200`, без фона, для карточек на белом фоне.
- **Тип Б — с заливкой**: `bg-stone-50`, без рамки. Использовать вместо типа А только когда секция уже белая и рамка не будет читаться.

Тень (`shadow-lg`/`shadow-sm`) — не атрибут карточки, а исключение для элементов, физически лежащих поверх фото или контента (плавающая плашка, залипающий header). Не добавлять тень обычным карточкам в сетке.

Внутренний отступ: `p-8` — стандарт для карточки с контентом; `p-6` — компактные/плавающие элементы.

## Поля формы

Единый паттерн для `input` / `textarea`:

```
w-full bg-transparent border px-5 py-4 text-white placeholder-stone-500
focus:outline-none transition-colors
border-stone-700 focus:border-stone-400
```

Состояние ошибки: заменить `border-stone-700` на `border-red-500`, под полем — `text-red-400 text-xs mt-1` с текстом ошибки.

`<select>` — единственное исключение: непрозрачный `bg-stone-900` вместо `bg-transparent` (нужно для читаемости нативного выпадающего списка), в остальном классы те же.

## Отступы и сетка

- Контейнер секции: `max-w-7xl mx-auto px-6` — всегда, без вариаций.
- Вертикальный ритм секции: `py-24` — для всех content-секций (Hero — отдельный случай, `min-h-screen`).
- Блок заголовка секции (эйбрау + H2) перед контентом: `mb-16`.
- Отступ под эйбрау-подписью до заголовка: `mb-4`.
- Зазор сетки — по плотности контента: `gap-6` (плотная сетка карточек-фото), `gap-8` (карточки услуг), `gap-16` (широкая двухколоночная раскладка).

## Короткие правила (свод)

1. Шрифт — только Georgia, serif. Не подключать другие.
2. Цвет текста/фона — только токены `stone-*`, `white`, `black`. Не заводить новый hex "около" существующего.
3. Капс-подписи — `tracking-[0.4em]` (эйбрау) или `tracking-widest` (интерактив). Третьего не давать.
4. Углы — всегда острые, `rounded-*` не использовать.
5. Тень — исключение для "плавающих" элементов, не стиль карточки по умолчанию.
6. Кнопка = один из 3 размеров × один из 4 цветовых вариантов выше — не изобретать новые сочетания padding/border.
7. Секция = `max-w-7xl mx-auto px-6` + `py-24` + заголовочный блок с `mb-16`.
